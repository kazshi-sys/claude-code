# claude-code

このリポジトリは、[Claude Code](https://claude.ai/code) を使った作業のためのプロジェクトです。

## このリポジトリについて

Claude Code (claude.ai/code) が本リポジトリ内で作業する際の運用方針は [CLAUDE.md](./CLAUDE.md) にまとめています。コミットやプルリクエストの作成に関するポリシーなど、作業を始める前に一読してください。

## 開発の進め方

- 変更はブランチを切って行い、ひと区切りついたらコミットします。
- プッシュやプルリクエストの作成については [CLAUDE.md](./CLAUDE.md) のポリシーに従ってください。
